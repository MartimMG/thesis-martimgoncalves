**The threshold system — three generations, read them in this order:**

| File | Status |
|---|---|
| `threshold.ipynb` | Superseded |
| `threshold_2.0.ipynb` / `threshold_2.0_copy.ipynb` | The rule as described in the write-up. The `_copy` is the working variant |
| `threshold_app.ipynb` | Derives the deployed thresholds and writes `deployed_model/` |

The rule itself: `t_high` = top 15% of risk at 5 years, `t_low` = a gap-based cut
around the 35th percentile, `t_intermediate` = mean risk. Result: ~15% of
patients flagged, capturing 100% / 94% / 78% of events at 1 / 3 / 5 years.

## Historical folders

**`pic/`** — the poster/pic work. Contains `selection/` and
`subsampling/` (model choice under class imbalance), `repeted_cv/` (repeated-CV
results and per-model SurvSHAP), `recalibration/` (Breslow vs. Harrell's
recalibration — Breslow won), `results/` (grid searches), `auc/`, `data/`, and
`figures/`.

**`treat+diag+surg/`** — the first serious pipeline: data cleaning
(`cleaning/` — collinearity and proportional-hazards checks), the progression
from categorical to continuous encoding (`before_continuous/` → `continuous/` →
`encoding/` → `final/`), Cox variants (`cox/`), a Bayesian Cox attempt
(`bayesian/`, not pursued), ensembles, and anomaly detection.

**`diagnostic/`** — Diagnostic variables only: EDA, univariate Cox
(`ucphm/`, in two styles), and ensembles.

**`treatment/`** — Treatment variables only, univariate Cox. 

**`neojuvant/`** — A different question (neoadjuvant treatment response
and tumour reduction, framed as classification) with its own data pipeline and
its own copy of `functions/`; not part of the thesis.

**`survshap-main/`** — the SurvSHAP authors' published code, vendored so the
explainability results are reproducible. Third-party, unmodified.

## Running it

```bash
conda env create -f dependencies.yml   # creates the env named survival-env-2
conda activate survival-env-2
```

`conda_commands.txt` is stale — it refers to an old project path, a file named
`environment.yml`, and an environment name that no longer exists. Use
`dependencies.yml` instead. Key pinned versions are recorded in
`new_approaches/models/5y/threshold_validation/run_metadata.json`
(Python 3.11.13, scikit-survival 0.25.0, lifelines 0.30.0).

Notebooks use paths relative to their own folder, so run them from where they
live. To reproduce the main result end to end:

1. `new_approaches/data/data_cox/new_new_data.ipynb` → `data.csv`
2. `new_approaches/models/5y/cox.ipynb` → the fitted model
3. `new_approaches/models/5y/threshold_app.ipynb` → `deployed_model/`
4. `new_approaches/models/5y/threshold_validation/` scripts → the validated numbers
